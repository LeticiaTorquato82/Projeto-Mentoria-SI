# ✅ Processo de Validação

## Objetivo

Garantir que cada funcionalidade da API siga critérios de qualidade e corretude.

## Etapas recomendadas

1. validar entrada de dados
2. verificar status e mensagens de erro
3. confirmar regras de negócio
4. executar testes automatizados
5. validar coleção Postman
6. revisar relatórios de execução

## Critérios de aceitação

- criação de tarefa com payload válido
- retorno correto de 201
- consulta por ID retorna o dado esperado
- status inválido retorna 400
- recurso inexistente retorna 404
- exclusão remove corretamente o registro

## Observações

Esse processo pode ser usado como base para documentação de qualidade, relatórios e processos acadêmicos.
