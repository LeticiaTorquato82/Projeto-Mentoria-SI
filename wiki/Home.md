# 🧩 Wiki do Projeto

Bem-vindo à documentação do projeto `Task Management API`.

Esta wiki reúne os principais conceitos, fluxos de uso, arquitetura e processo de validação do sistema.

## 📌 Visão Geral

Este projeto foi desenvolvido para demonstrar uma API REST e GraphQL para gerenciamento de tarefas de sprint, com foco em:

- qualidade de software
- validação de contratos
- testes automatizados
- integração contínua
- documentação em código e processo

## 🏗️ Visão da Solução

O projeto é composto por:

- API REST com Express
- API GraphQL
- validação de schemas com Ajv
- camada de persistência leve em arquivo
- testes automatizados com Jest e Supertest
- coleção de testes com Postman/Newman
- relatórios de execução e performance

## 🚀 Como executar

```bash
npm install
npm start
```

A API ficará disponível em:

```text
http://localhost:3000
```

## 🧪 Como testar

```bash
npm test
```
